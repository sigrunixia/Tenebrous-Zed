# Tenebrous-Zed
Zed theme for my Tenebrous Coloration

## Colors only Zed uses

Most colors come from the shared palette in [Tenebrous](https://github.com/sigrunixia/Tenebrous). The dim terminal shades are only for Zed, so they live here in `palette.json`, and the Tenebrous build reads them when it writes the theme. Contrast is against Background (`#0d0f14`).

| Where it shows up | Color | Hex | Contrast | WCAG |
|---|---|---|---|---|
| Terminal dim red | red-dim | `#a8473a` | 3.31 | Large text and UI only |
| Terminal dim blue | blue-dim | `#5d7fb0` | 4.68 | AA |
| Terminal dim purple | purple-dim | `#8070b0` | 4.44 | Large text and UI only |
| Terminal dim cyan | cyan-dim | `#4a8f9c` | 5.20 | AA |
